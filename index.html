SpaceBatch — Bulk Label, CQL & Page Matrix

Commercial B2B Administration Add-on for Atlassian Confluence Cloud
Product Overview & Pricing Privacy Policy Support & SLA

SpaceBatch is a commercial B2B SaaS administration utility built on the official Atlassian Forge platform for Confluence Cloud administrators. It enables organizations to inspect full space page trees or cross-space CQL queries, preview deterministic dry-run label diffs, and execute throttled batch updates directly inside the browser without third-party proxy timeouts.

Key Enterprise Capabilities

  • Space & Advanced CQL Page Matrix: Load all pages in any Confluence space or run custom CQL queries (e.g. type=page AND label="legacy-v1") across your site.
  • Bulk Label Governance: Rename/Merge, Add, Remove, or Purge labels across hundreds of pages in a single operation.
  • Deterministic Dry-Run Diff Preview: Review exact +added and -removed changes per page before a single API write executes.
  • Automatic Rate-Limit Backoff: Honours Confluence Cloud HTTP 429 Retry-After headers automatically.
  • In-Browser CSV & JSON Audit Exports: Download page matrices and timestamped execution logs directly from browser memory.
